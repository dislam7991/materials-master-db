## Judgment calls

- **The new tab sits first**, ahead of "Material lookup", because the task
  calls it the way in for someone who does not know which catalog to ask. It
  changes which tab the app opens on, which is the one existing behaviour this
  touches — easy to move if that is unwanted.
- **One results table, not a searchbox-and-detail view** like the other tabs. A
  labelled row answers "which side is this on?"; a detail view would be the
  third copy of a panel the task rules out.
- **A lab-only row shows blank stock, not `0`** — zero would be a claim about
  warehouse stock for something the warehouse has never heard of.
- **README updated in the same commit**: its Status line named E5 as what
  remained, and "Four tabs" became five. Same precedent as D2 and as the commit
  that added E5.
